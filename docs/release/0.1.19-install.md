## 安装与覆盖更新

首次安装运行 `qingtu-0.1.19-windows-x64-setup.exe`。

已有轻图：解压 `qingtu-0.1.19-update.zip`，先保存当前编辑，再运行 `覆盖更新.cmd`，选择原程序目录。沿用相同应用标识和资料库格式，导图、图片、文件夹与顶部标签继续使用。更新脚本会请求旧程序正常退出，旧程序未退出时不会强制结束进程。

本次不在用户原安装目录执行安装；桌面验证使用独立配置目录与隔离资料库。

## 使用方法

1. 双击内容卡片的正文进入编辑。
2. 点击原有的“代码块”按钮。光标位于代码块中时，顶部浮动工具栏会显示“代码语言”。
3. 将语言选择为 **Mermaid 图表**，然后输入图表源码。源码下方显示实时预览。
4. 点击“完成编辑”或按 Esc，正文显示图表。点击“放大图表”可全窗口查看、滚轮缩放、拖动平移；Esc 返回。
5. 阅读时可展开“查看源码”；再次进入正文编辑即可修改。修改过程中语法不完整会显示错误，修正后恢复预览，源码始终保留。

也可以直接将标准 Markdown 围栏粘贴到正文：

````markdown
```mermaid
flowchart LR
  A[提出想法] --> B[制作下一版]
  B --> C[试用反馈]
```
````

围栏是三个英文反引号，即键盘数字 1 左侧按键的字符。逐字输入 ` ```mermaid ` 后按 Enter 也可创建该代码块。新代码块默认仍为普通代码，可以随时在同一语言选项中切换。

## 直接体验

- 在轻图的“导入项目”中选择 `Mermaid图表体验.qmap`，包含流程图、饼图、时序图、思维导图与甘特图五张卡片。
- `Mermaid图表示例.md` 提供相同五种图表的源码，复制任一完整围栏粘贴到正文即可。
- `图表源码与实时预览.png`、`图表导图预览.png`、`图表全窗口预览.png` 是真实桌面程序的截图，`图表完整导出.png` 是程序生成的完整导图 PNG。

Pele 1.6.0 固定版本随程序打包，普通图表不需要联网服务。使用 Mermaid 语法，布局与主题由 Pele 处理，与 Mermaid 原版的外观会有差别。图表作为正文中的一个代码块保存，其内部元素不作为画布上的独立导图节点。图中外部链接与外部图片不启用。

此版本验证五类代表图表及 Markdown 编辑回归，未逐项验收全部图表类型。详细结果、正式程序 SHA256 与源码指纹见本目录的验证文件。
