> 历史版本说明：此版本的旧安装程序、覆盖更新包和原始构建源码附件已撤下。请前往 [最新发布页](https://github.com/Pxyfcywl/qingtu/releases/latest) 下载。下文保留原版本功能与验证范围。

2026-10-28，Windows x64。[GitHub 发布页](https://github.com/Pxyfcywl/qingtu/releases/tag/v0.1.23)。本版包含全页 Markdown 编辑，以及 0.1.21、0.1.22 本地预览阶段的导航调整。

## 安装与更新

- 首次安装：下载并运行 `qingtu-0.1.23-windows-x64-setup.exe`。
- 已有旧版：下载并解压 `qingtu-0.1.23-update.zip`，保存正在编辑的内容后运行“覆盖更新.cmd”，选择原程序目录。

更新沿用原有资料库，不需要重新导入导图。程序目录与资料库是独立的位置。更新脚本请求旧程序正常保存并退出，不强制结束进程。缺少 WebView2 时，安装器需要联网获取运行时。

## 本次调整

移除 Markdown 全页编辑底部的操作提示，以及“当前卡片 / 正文自动同步 · 保留双栏布局”状态栏。即时编辑、源码和分屏中的正文区域延伸到窗口底部。

当前卡片在顶部独立标签页编辑，视图切换、大纲开关和返回操作统一位于主导航栏。正文区不再显示重复的卡片标题行。完整操作与双栏源码示例见 [Markdown 全页编辑指南](../markdown-workspace.md)。

卡片名称可在顶部标签页查看，保存状态由顶部“已保存 / 保存中”显示。正文继续自动同步到原卡片。双栏、公式、代码、Mermaid、本地图片与视频沿用现有功能。

## 使用

从 MD 卡片右上角的“全页编辑卡片”，或选中卡片后点击主导航栏“Markdown 编辑”打开。顶部可切换即时编辑、源码和分屏，也可收起大纲或返回导图。

`Ctrl+/` 切换即时编辑和源码，`Ctrl+S` 保存，`Ctrl+Z` 撤销，`Ctrl+Shift+Z` 重做，Esc 返回导图。

源码中的双栏与专有内容继续使用扩展语法及 `qingtu-node-json` 保留块；未完成的扩展源码会保留在当前页，补全后继续同步。卡片仍遵循原有的 200 个块和 20,000 字符限制。
