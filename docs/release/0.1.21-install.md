# 轻图 0.1.21 · Markdown 全页编辑

2026-10-28，Windows x64。本版为历史本地预览，未单独发布；功能已合入 0.1.23 公开版。以下保留当时的本地文件名，公开下载请使用 [0.1.23](0.1.23-install.md)。

## 安装与更新

运行 `轻图-0.1.21-Windows-x64-安装.exe` 安装。已有旧版时，可下载并解压 `轻图-0.1.21-覆盖更新包.zip`，保存正在编辑的内容后运行“覆盖更新.cmd”，选择原程序目录。更新沿用原有资料库，不需要重新导入导图。

程序目录与资料库是两个独立位置。覆盖更新脚本会请求旧程序正常保存和退出，不强制结束进程。首次安装在缺少 WebView2 时需要联网获取运行时。

## 打开当前卡片

- 点击 MD 内容卡片右上角的“全页编辑卡片”按钮。
- 或选中一张 MD 内容卡片，点击顶部“Markdown 编辑”。
- 在卡片原有编辑工具栏中也可以点击“全页编辑卡片”。

卡片会在顶部独立标签页中打开。每个标签对应一张原卡片，不汇总整张导图。左侧是本文大纲，右侧为完整编辑区；不显示额外的卡片同步预览栏。大纲可通过右上角按钮收起。

## 编辑与保存

- **即时编辑**：直接编辑排版后的正文，沿用原有公式、代码、表格、图片和视频工具。支持标题格式选择、插入双栏和切换双栏比例。
- **源码**：编辑 Markdown 文本，合法修改自动更新原卡片。
- **分屏**：左侧编辑源码，右侧查看正文排版。此处的右侧是用户主动选择的 Markdown 分屏预览，不是常驻卡片同步栏。
- `Ctrl+/` 切换即时编辑与源码，`Ctrl+S` 保存，`Ctrl+Z` 撤销，`Ctrl+Shift+Z` 重做。点击“返回导图”、完成编辑或按 Esc 返回画布。

页面使用原卡片的数据和自动保存机制。原卡片的名称仍在导图中修改，正文内的标题通过 Markdown 或格式工具编辑。

## 双栏与本地媒体

标准 Markdown 没有双栏语法，本版采用如下扩展格式；也可以通过即时编辑工具栏操作：

```text
:::columns 3:2
:::column
## 左栏标题

左栏正文
:::column
## 右栏标题

右栏正文
:::
```

比例支持 `3:2` 和 `1:1`，双栏不能嵌套。正文原有的图片、视频、合并表格和无法无损表示为普通 Markdown 的格式，用 `qingtu-node-json` 保留块保存。它们在即时编辑与分屏中正常显示；编辑其它文字不会删除保留块中的数据。暂不提供将这些本地媒体自动发布成公网 Markdown 图片链接的功能。

未完成的双栏、损坏的保留块、超过正文限制的内容会显示错误，草稿继续保留在当前页，并阻止切换或关闭该页。补全源码后继续自动同步，最后一次有效正文不会被错误内容覆盖。源码模式支持本应用既有正文结构，不承诺完整兼容 Typora 的全部扩展语法。

卡片仍遵循原有正文限制：最多 200 个块和 20,000 字符。Markdown 编辑标签在本次运行中保留；退出后可从原卡片再次打开，已保存的正文和媒体会保留。
