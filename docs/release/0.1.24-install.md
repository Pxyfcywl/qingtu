# 轻图 0.1.24 · 单卡片 Markdown 演示

2026-10-28，Windows x64。[GitHub 发布页](https://github.com/Pxyfcywl/qingtu/releases/tag/v0.1.24)。本版在已验证的同一应用源码上重新构建，通过编译路径映射移除本机工作目录，功能与本地体验版一致。

## 安装与打开

运行 `qingtu-0.1.24-windows-x64-setup.exe`。已有旧版可解压 `qingtu-0.1.24-update.zip`，保存编辑后运行“覆盖更新.cmd”，选择原程序目录。资料库沿用原有位置。

打开一张 MD 内容卡片的全页编辑，在主导航栏点击“演示”。只播放当前卡片，不合并其它卡片。[完整演示指南](../markdown-presentation.md)。

## 分页规则

- 根据正文标题建立章节；主标题及二级标题通常另起一页。文档从较低层级标题开始时，按实际标题层级识别章节。
- 页内保留所属章节路径。内容跨页后沿用标题，并显示“续页”，不使用 AI 补写标题、摘要或衔接句。
- 依据实际渲染高度分页。长段落按可保留行内样式的文本片段拆分；列表按条目拆分并延续有序编号；普通代码按原文片段拆分；简单表格分页后重复表头。
- 双栏、Mermaid 图表、图片、公式和复杂内容优先保持完整。大块内容无法放入一页时保留滚动查看，并提供“展开长内容”，避免删除、裁切或把文字无限缩小。
- 独立的 Markdown `---` 水平分隔线作为手动分页；代码块中的分隔符不参与分页。

演示按固定 16:9 页面排版，根据窗口大小等比例显示。目录可收起，小窗口默认优先留出正文空间。图片和图表限制在页面可用区域内，Mermaid 仍可通过“放大图表”打开原有缩放查看器。

## 操作

- 右 / 下方向键、PageDown、空格：下一页。
- 左 / 上方向键、PageUp：上一页。
- Home / End：第一页 / 最后一页。
- 左侧目录：跳转页面；顶部目录按钮可收起或展开。
- 顶部“全屏”：进入系统全屏，可通过“退出全屏”返回。
- “退出演示”或 Esc：返回原编辑视图。放大图表或展开长内容时，先关闭当前查看窗口。

底部翻页控件在不操作时淡出，不设置常驻正文状态栏。视频按原有本地视频组件播放，翻页离开时释放播放器。

## 保存与限制

开始演示前提交有效编辑；未完成或无效的扩展源码需要先补全。播放使用正文快照，不修改卡片原文、标题层级或导图结构。退出后继续原编辑视图。

本版重点试验布局效果，分页规则仍可继续调整。特别长的双栏、嵌套列表、复杂表格或单个内容块可能需要滚动 / 展开阅读；超长图中的文字需通过放大图表查看。第一版暂不提供逐页人工合并、单独的演示设置保存或 PPTX 导出。

卡片仍遵循现有的 200 个块和 20,000 字符限制。验证使用隔离的测试资料库，不在用户原目录运行安装；验证记录中区分单元、相关界面回归和独立桌面检查，不代表全部历史性能或干净系统安装验收通过。
