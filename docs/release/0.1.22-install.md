# 轻图 0.1.22 · 精简 Markdown 编辑导航

2026-10-28，Windows x64。本版为历史本地预览，未单独发布；功能已合入 0.1.23 公开版。以下保留当时的本地文件名，公开下载请使用 [0.1.23](0.1.23-install.md)。

## 安装与更新

- 首次安装：运行 `轻图-0.1.22-Windows-x64-安装.exe`。
- 已有旧版：解压 `轻图-0.1.22-覆盖更新包.zip`，保存正在编辑的内容后运行“覆盖更新.cmd”，选择原程序目录。

更新会沿用已有资料库，不需要重新导入导图。程序目录和资料库是独立的位置。更新脚本请求旧程序正常保存并退出，不强制结束进程。缺少 WebView2 时，安装器需要联网获取运行时。

## 本次调整

Markdown 编辑页的“即时编辑 / 源码 / 分屏”、大纲开关及“返回导图”合并到上方主导航栏。

删除原先单独显示“卡片名称 / Markdown”的整行。正文格式工具栏直接位于主导航栏下方，让正文获得更多纵向空间。卡片名称仍显示在顶部独立标签页和底部状态栏。

窄窗口下会精简部分图标和文字，三个编辑视图、大纲开关及返回操作仍可使用。返回导图后，主导航栏恢复导图工具。

## 编辑方式

选中一张 MD 内容卡片后，点击顶部“Markdown 编辑”；也可以使用卡片右上角的“全页编辑卡片”。每个 Markdown 标签对应一张原卡片，正文修改自动同步到原卡片。

- 即时编辑：直接编辑排版后的内容，保留正文工具栏。
- 源码：编辑 Markdown 文本。
- 分屏：同时编辑源码和查看排版结果。
- `Ctrl+/` 切换即时编辑和源码，`Ctrl+S` 保存，`Ctrl+Z` 撤销，`Ctrl+Shift+Z` 重做。
- 点击主导航栏“返回导图”或按 Esc 返回画布。

双栏、公式、代码、Mermaid、本地图片和视频继续保留。双栏与复杂格式沿用 0.1.21 的扩展语法及 `qingtu-node-json` 保留块；未完成的扩展源码保留在当前页，补全后继续同步。卡片仍遵循原有的 200 个块和 20,000 字符限制。
