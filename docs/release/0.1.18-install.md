## 使用方法

在内容卡片中双击进入正文编辑：

1. 点击“有序列表”，或输入 `1.` 加空格开始列表；普通段落按 Tab 也可开始有序列表。
2. 输入第一项，按 Enter 新增同级条目。
3. 在新条目中按 Tab，使它成为上一项的子项，编号显示为 `1.1`。
4. 再按 Enter 新增条目，随后按 Tab，可形成第三级 `1.1.1`。
5. Shift+Tab 提升一级；Enter 添加同级条目。首项没有可归属的上一项时，Tab 保持当前层级，焦点仍留在正文。

示例显示：

```text
1. 第一部分
   1.1 子部分
       1.1.1 详细内容
       1.1.2 同级内容
   1.2 下一个子部分
2. 第二部分
```

列表使用真实的嵌套结构；层级编号由结构自动生成，编辑、阅读和重新打开一致，已有嵌套有序列表也会显示层级编号。原有非默认起始编号继续保留。无序列表同样支持 Tab 缩进和 Shift+Tab 提升。

正文中的 Tab 不会新增导图节点或移动到下一个控件。代码块中 Tab 插入四个空格，Shift+Tab 减少行首缩进；表格中 Tab/Shift+Tab 切换下一格/上一格，最后一格 Tab 可新增一行。Esc 完成正文编辑后，画布上的 Tab 仍按原有方式新增子节点。

## 覆盖更新

解压 `qingtu-0.1.18-update.zip`，保存当前编辑，运行 `覆盖更新.cmd`，选择原程序目录，例如 `E:\轻图`，目录中应有 `qingtu.exe`。脚本请求旧版正常保存退出后，再使用安装器更新模式覆盖程序；旧版未正常退出时不强制结束进程。

应用标识仍为 `com.qingtu.mindmap`，沿用原资料库、素材、文件夹和顶部标签，无需重新导入导图。首次安装可直接运行安装包，需要时由普通安装包下载 WebView2。
