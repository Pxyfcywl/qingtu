> 历史版本说明：此版本的旧安装程序、覆盖更新包和原始构建源码附件已撤下。请前往 [最新发布页](https://github.com/Pxyfcywl/qingtu/releases/latest) 下载。下文保留原版本功能与验证范围。

## 安装与更新

首次安装运行 qingtu-0.1.20-windows-x64-setup.exe。已有旧版请解压 qingtu-0.1.20-update.zip，保存编辑后运行“覆盖更新.cmd”，选择原程序目录。脚本请求旧程序正常退出后更新，不强制结束进程。沿用原有资料库与素材，无需重新导入导图。

## 图表查看

点击卡片中的“放大图表”，在图形或空白区域按住左键拖动即可平移，无需先滚轮放大。滚轮以鼠标位置缩放，上方按钮可缩小、放大或适应窗口；松开左键停止移动，Esc 返回正文。

图表很长时，可以在保持放大比例的情况下反复向上拖动，直到最下方节点进入窗口；反向拖动可返回顶部。缩放或移动不会改变图表源码。

附带 Mermaid图表体验.qmap、Mermaid图表示例.md 与超长图平移示例.md，可分别导入项目或复制代码到正文。依旧使用标准 Mermaid 语法与本地 Pele 1.6.0 引擎。

## 验证

58 项单元、87 项完整界面测试、21 项独立桌面检查通过。长图测试有 81 个节点，放大后约 14,783 像素高，在约 784 像素高的窗口中拖到步骤 81，再拖回步骤 1，保持放大比例。独立验证与正式构建前端全部 SHA256 一致。
