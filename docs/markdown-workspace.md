# Markdown 全页编辑

从 0.1.23 开始，公开版轻图支持在独立标签页中编辑当前 MD 内容卡片。每个标签对应一张原卡片，修改自动同步到该卡片，不会把整张导图的卡片合并成一篇文档。

![即时编辑与主导航栏](media/markdown-workspace.png)

## 打开和返回

点击内容卡片右上角的“全页编辑卡片”；也可以选中一张内容卡片后点击主导航栏“Markdown 编辑”。卡片原有的正文编辑工具栏中也有全页编辑入口。

使用主导航栏“返回导图”、正文工具栏“完成编辑”或 Esc 返回画布。独立标签在本次运行中可以再次切换；关闭标签不会删除卡片。退出程序后，可从原卡片重新打开，已经保存的正文和素材会保留。

卡片名称显示在顶部标签中，在导图中修改。正文中的标题由编辑区或 Markdown 源码修改，左侧本文大纲会根据正文标题生成，点击可定位；主导航栏的大纲按钮可以收起或展开它。

## 三种编辑视图

| 视图 | 用法 |
| --- | --- |
| 即时编辑 | 直接编辑排版后的正文，使用工具栏设置标题、列表、表格、公式、双栏和媒体 |
| 源码 | 编辑 Markdown 文本，合法修改自动同步到原卡片 |
| 分屏 | 左侧编辑源码，右侧查看同一正文的排版结果 |

三种视图的入口都位于主导航栏。正文区不再设置重复标题行、常驻卡片同步预览栏或底部提示状态栏。保存状态由主导航栏的“已保存 / 保存中”等提示显示。

![源码与排版分屏](media/markdown-source-split.png)

`Ctrl+/` 切换即时编辑与源码，`Ctrl+S` 保存，`Ctrl+Z` 撤销，`Ctrl+Shift+Z` 重做。即时编辑中列表使用 Tab 缩进、Shift+Tab 提升层级；代码块处理自己的缩进。

## 演示当前卡片

从 0.1.24 开始，全页编辑的主导航栏提供“演示”。按照当前卡片的标题和实际内容高度分页播放，支持目录、续页标题和全屏；退出后继续编辑。完整规则、操作与限制见 [Markdown 演示指南](markdown-presentation.md)。

## 双栏

即时编辑工具栏提供插入双栏和切换比例的操作。把光标放入双栏后，可以在 `1:1` 与 `3:2` 之间切换。标准 Markdown 没有双栏语法，轻图源码视图使用以下扩展：

```text
:::columns 3:2
:::column
## 核心原则

- 主动回忆
- 间隔练习
:::column
## 实践步骤

1. 明确目标
2. 完成练习
:::
```

左栏和右栏分别由两个 `:::column` 标记开始，最后用单独一行 `:::` 结束。比例也可写成 `1:1`，双栏不能嵌套。源码工具区的“插入双栏”可以插入此结构。

## 公式、代码与本地媒体

公式使用 `$...$` 或独立的 `$$` 数学块；代码使用 Markdown 围栏，Mermaid 使用 `mermaid` 语言。即时编辑中仍可直接使用原有插入与编辑工具。

图片、视频、合并表格和部分复杂格式无法无损表示为普通 Markdown，因此源码视图使用 `qingtu-node-json` 保留块保存它们的结构和素材引用。切换视图或修改其它段落会保留这些内容；不要随意删除保留块或更改其中的素材标识。图片和视频建议在即时编辑中通过媒体工具插入。

正文仍以轻图的结构化数据保存，独立编辑是同一张卡片的编辑视图。它不把整个导图转换成标准 `.md` 文件，也不承诺支持 Typora 的全部扩展语法。分享包含媒体的完整内容时，使用 `.qmap` 项目导出。

## 未完成的源码

未完成的双栏、损坏的保留块或超过正文限制的内容会显示错误，草稿保留在当前页，并阻止离开或关闭当前编辑页。补全源码后继续自动同步，最后一次有效正文不会被错误内容覆盖。

卡片继续遵循最多 200 个块和 20,000 字符的正文限制。较长内容可以拆分为多张卡片。
