# Markdown 演示

从 0.1.24 开始，在 MD 内容卡片的全页编辑顶部点击“演示”，即可把当前正文作为 16:9 幻灯片播放。不使用 AI，不补写标题、摘要或衔接句，也不会合并其它卡片。

![双栏演示页面](media/markdown-presentation.png)

## 标题和分页

演示根据标题层级建立章节，并依据实际渲染高度分页。主标题及二级标题通常另起一页；文档从较低层级标题开始时，按实际层级识别章节。页内保留所属章节路径，跨页后沿用章节标题并显示“续页”。

长段落保留行内样式，列表按条目拆分并延续有序编号，普通代码按原文片段拆分，简单表格跨页后重复表头。独立的 Markdown `---` 水平分隔线作为手动分页；代码块中的分隔符不参与分页。

双栏、Mermaid、图片、公式和复杂内容优先保持完整。无法放入一页的大块内容保留滚动查看，并提供“展开长内容”；不会删除或裁切原文，也不会无限缩小字号。图表仍可使用“放大图表”进入原有缩放查看器。

![图表与公式演示页面](media/markdown-presentation-diagram.png)

## 播放操作

| 操作 | 用途 |
| --- | --- |
| 右 / 下方向键、PageDown、空格 | 下一页 |
| 左 / 上方向键、PageUp | 上一页 |
| Home / End | 第一页 / 最后一页 |
| 左侧目录 | 跳转页面 |
| 顶部目录按钮 | 收起或展开目录 |
| 顶部全屏按钮 | 进入或退出系统全屏 |
| Esc、退出演示 | 返回原编辑视图；有放大或展开窗口时先关闭该窗口 |

页面根据窗口大小等比例显示，小窗口默认优先留出正文空间。底部翻页控件在不操作时淡出。视频沿用本地播放器，翻页离开时释放媒体源。

## 保存和限制

开始演示前提交有效编辑；未完成或无效的扩展源码需要先补全。播放使用已提交正文的快照，退出后当前卡片原文和其它卡片均保持不变。

首版暂不提供逐页人工合并、单独保存演示设置或 PPTX 导出。超长双栏、嵌套列表、复杂表格等完整块可能需要滚动或展开阅读，超长图中文字需要放大查看。卡片仍遵循现有的 200 个块和 20,000 字符限制。
